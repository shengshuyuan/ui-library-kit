# 0.4.1 行为评测记录

日期：2026-11-07。评测对象：0.4.1 的 SKILL.md 与 references。方法见 [README](README.md)。

## 运行方式

- 一个全新的子代理，只给技能路径与五个案例 prompt，不给 expected；禁止读取 evals、CHANGELOG、README，不安装、不联网、不改文件。
- 五个案例在同一会话中回答，共享上下文；评测者与技能作者同一模型家族。结果用于检查决策边界，不是独立统计样本，不与 0.4.0 做量化对比。

## 真实项目使用

同一组规则先在一个 Next.js 16、手写 CSS 的网站上实际使用：逐路由在 1280 与 375 宽度截图和测量，发现后台登录页 class 无样式、详情页主按钮排在分享框之后、正文小标题缺少下间距，全部用现有样式变量修复，未新增依赖。随后 lint、单元测试、端到端测试与浏览器复查通过；其中一次端到端超时经定位为测试脚本过时（表单出错后已自动展开折叠区，脚本又点了一次把它关上），已修正脚本而非跳过。该项目代码不随技能分发。
