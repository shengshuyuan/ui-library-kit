# React Bits
核实日期：2026-11-05。适合创意落地页、文本动画、背景与局部微交互。

- 官网：https://www.reactbits.dev/
- 安装：https://www.reactbits.dev/get-started/installation
- 源码：https://github.com/DavidHDev/react-bits
- 许可：https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md

官方安装页支持源码复制及 shadcn registry，示例：`npx shadcn@latest add @react-bits/SplitText-TS-TW`。后缀选择 JS/TS 与 CSS/Tailwind，按项目选择，不机械复用示例。具体条目的依赖、SSR/client 边界和导入路径以当前源码为准。

仓库标注 MIT + Commons Clause，不能把它简写成纯 MIT 或把本技能 MIT 许可套用到该库。另有 Pro 内容，本技能仅使用免费条目并核对条件。本技能只保存入口，不收录或再分发组件源码。

动效需服务信息表达；背景/shader/粒子效果先考虑设备性能、可读性和 reduced-motion。业务后台无需默认引入这些效果。

验证程度：CountUp-TS-CSS 已通过官方 shadcn CLI 安装，在 React 19 / Tailwind 4 示例完成类型检查、构建和浏览器渲染；不代表所有组件或 Next.js SSR 已验证。
